# Identité visuelle

Le nom du site, son logo, ses couleurs et son adresse de contact se règlent dans l'administration. Dans la barre latérale, ouvrez **Paramètres** puis **Identité visuelle**.

Tous les champs sont facultatifs : laissés vides, le site garde son nom et son apparence par défaut.

## Identité

| Champ | Description |
|---|---|
| **Nom du site** | Dans l'en-tête, le titre des pages et les emails envoyés |
| **Slogan** | Sous le nom, en bas de chaque page |
| **Email de contact** | Affiché en bas de chaque page. Les modèles de page s'en servent aussi pour « Contact : … » |

## Apparence

| Champ | Description |
|---|---|
| **Logo** | Remplace le symbole dans l'en-tête, le pied de page et l'administration. Il sert aussi d'icône dans l'onglet du navigateur : préférez une image carrée |
| **Couleur principale** | Boutons, liens et mises en avant, au format `#rrggbb` (par exemple `#e94f37`). Choisissez une couleur assez foncée pour rester lisible sur fond blanc |
| **Couleur secondaire** | Sections sombres et certains badges, au format `#rrggbb` |
| **Photo de l'inscription** | À côté du formulaire d'inscription, sur grand écran. Sans photo, le panneau prend la couleur secondaire |

Le texte des boutons s'adapte tout seul : clair sur une couleur foncée, foncé sur une couleur trop claire.

## Modèles de page

Quand vous partez d'un [modèle](modeles.md), le nom du site, celui du [territoire](carte.md#territoire) et l'email de contact sont repris dans les textes proposés. Sans email de contact, le texte affiche `[adresse de contact]` : remplacez-le.
