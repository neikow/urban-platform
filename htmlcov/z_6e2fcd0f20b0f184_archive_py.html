1"""The content archive: what moves between environments, and how it is checked. 

2 

3Publications (projects, events), pedagogy cards and the home page move between 

4environments (production → staging) with the images and documents they use, 

5in a ``.zip``: a ``manifest.json`` and the media files. 

6 

7* **Two import modes.** "Replace" keeps media primary keys (StreamField and 

8 rich text refer to media by id) and updates pages with the same slug under 

9 the same index page. "Create" never changes what exists: media whose id is 

10 taken by another file get a new id, references are rewritten 

11 (:func:`remap_media_ids`), and every page is created anew. 

12* **Authenticity.** With ``CONTENT_TRANSFER_KEY`` set (the same on both 

13 sides), the manifest is signed (HMAC-SHA256) on export and the signature is 

14 required on import. The manifest holds each file's SHA-256, checked too. 

15* **Untrusted input.** An archive is checked before anything is read from it: 

16 member names, sizes, the page models and the media extensions it may contain. 

17"""
